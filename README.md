# 🕒 Catálogo de Relógios

Sistema simples de cadastro, listagem, edição e exclusão de relógios. Utiliza **C# .NET Minimal API** com **SQLite** no backend e **HTML/CSS/JavaScript puro** no frontend.

## 🚀 Tecnologias Utilizadas

### Backend
- [.NET8 API]
- [SQLite](https://www.sqlite.org/index.html)
- [Entity Framework Core](https://learn.microsoft.com/ef/core/)

### Frontend
- HTML5
- CSS3
- JavaScript Vanilla (Fetch API)

---

## 💻 Funcionalidades

- ✅ Listar relógios cadastrados
- ✅ Adicionar novos relógios
- ✅ Editar relógios com formulário em popup
- ✅ Deletar relógios
- ✅ Comunicação com backend via REST API

## 🛠️ Como Executar o Projeto

### Pré-requisitos
- .NET SDK 8.0+
- SQLite (ou algum cliente de visualização como DB Browser for SQLite)
- Git instalado


### 1. Clone o repositório


```bash
git clone (https://github.com/Wors95/Minuta.git)
cd SiteRelogios
```

### 2. Clone o repositório

```bash
dotnet restore
```

# 3. Execute a aplicação

```bash
dotnet run
